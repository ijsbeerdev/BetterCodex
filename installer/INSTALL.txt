BLACKBOX FOR CODEX

1. Extract this entire ZIP to a folder.
2. Double-click "Install Blackbox.cmd".
3. Quit Codex completely, then open Codex normally.
4. Click the package icon beside the Help (?) button.

To remove Blackbox, double-click "Uninstall Blackbox.cmd".

Blackbox does not modify the signed Codex installation. It installs a reversible
per-user launcher and runtime under Local AppData.
